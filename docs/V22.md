# V22 — mantenimiento y lifecycle

- `user.model.js` y los wrappers de modelos sin consumidores fueron eliminados.
- `api.js` es la única capa de acceso RPC del frontend.
- Las páginas usan `PageLifecycle` con `mount`, `bindEvents`, `unbindEvents` y `destroy`.
- La página de juego destruye explícitamente el controlador activo en `pagehide`.
- `schema.sql` contiene una sola definición final de cada RPC administrativa.
- Las migraciones históricas no se fusionan en el esquema final; sirven para actualizar bases existentes.
